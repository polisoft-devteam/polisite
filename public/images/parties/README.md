# Party logos

One file per party, named after its key in `src/lib/election.ts`: `l.webp` is Liberalerna,
`sd.webp` Sverigedemokraterna, `nyans.webp` Partiet Nyans. The filename is the whole
connection, as with badges.

Drop them in and run `pnpm images:optimize`. A party with no file shows its abbreviation
instead, which is what all fourteen do until somebody adds one.

These are other people's trademarks. Fine on a private page for ten members; do not put
them on anything public.
